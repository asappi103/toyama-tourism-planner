# 富大生発 -富山のまちなか観光ルートの開発- | TOYAMA NAVI LAB — Design Your Own Toyama.

富山大学 都市デザイン学部のフィールドワーク知見をもとに、出発地・観光可能時間・スタート/終了時刻・移動手段・優先カテゴリから最適な観光ルートとタイムラインを算出し、OpenStreetMap（Leaflet）上に可視化する観光ルートプランナーです。

## 主な機能

- **最適観光ルート算出 & タイムライン表示**
  - 出発拠点（富山駅・富山高山すし空港・新高岡駅・カスタム追加拠点）と15分刻みの観光スタート/終了時刻、8段階の観光可能時間プラン（1時間〜2泊3日）に対応。
  - ルート内スポットの順序入れ替え（↑/↓）、削除、追加、滞在時間の微調整（±15分）に対応。
- **モデルルート一覧**
  - 各出発拠点別 × 各観光可能時間ごとのモデルルートを収録。
  - スポット紹介前に「総滞在時間・予算（目安）・総移動距離」を提示し、各スポットの名称・写真・一文で伝える学生目線の魅力を掲載。
- **OpenStreetMap（Leaflet）インタラクティブマップ**
  - 5カテゴリ色（体験・景色・食・交通・宿泊）× ルート訪問順序番号を組み合わせた丸型 `●` アイコン（ズーム縮尺・近接距離に応じた自動サイズ調整）。
  - 「カテゴリ表示」バーにて「出発地」および5カテゴリの表示/非表示を切り替え可能。
  - 選択スポットの前後ルートのみ表示モード（前区間＝グレー、次区間＝青色）と全体ルート表示の切り替えに対応。
- **スポット情報の再編集 & 写真ギャラリー（最大10枚・左右スワイプ対応）**
  - `.jpg / .jpeg / .png / .webp / .svg / .heic / .heif` 画像ファイルを最大10枚まで登録可能。左右スワイプ（タッチ・マウスドラッグ）で写真を切り替え表示。
  - 学生コメントの担当調査班（富山湾クルーズ班 / 食・魚市場プロジェクト班 / 体験型観光班 / 交通・データ班 / 景色班）の選択および CSV / JSON 入出力に対応。

## セットアップ・起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番用ビルド
npm run build
```
